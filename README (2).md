## 🚀 How to Build and Install

### 1. Clone and Install

```bash
git clone [https://github.com/glennsvel90/unclutter-remix.git](https://github.com/glennsvel90/unclutter-remix.git)
cd unclutter-remix
bun install --frozen-lockfile
bun run build
